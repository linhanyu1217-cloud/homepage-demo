# 地产公司公告 Agent

一个跑在你自己 Windows 电脑上的小工具：把每周收到的**公司公告**、
**新闻资讯**和**研报**，自动整理成一份 Word 周报和一个 PPT。

它只做两件事：**读你放进来的文件** → **生成周报**。
不联网抓数据、不上传任何文件、不删你的公告。

## 1. 这是什么

一个**个人工作用**的地产行业周报生成器。

你把一周的公司公告 PDF / Word / Excel 丢进 `02_待处理\` 目录，
运行一条命令，它就生成 Word 周报和 PPT。

它有两种用法：

| 用法 | 适合谁 | 怎么用 |
|---|---|---|
| **手动跑一次** | 想自己控制节奏 | `地产公司公告Agent.ps1 run` |
| **自动监听** | 想让电脑自己盯着 | `地产公司公告Agent.ps1 watch` |

---

## 2. 它能产出什么

每一次运行，会在 `05_输出\2026-W38\` 这样的目录里生成：

| 文件 | 是什么 |
|---|---|
| `本周公司公告汇总.md` | 本周公告的完整底稿（Markdown） |
| `本周公司公告周报.docx` | 上面那份排版好的 Word 周报 |
| `本周重要资讯.docx` | 本周行业资讯 |
| `房地产周报_2026.09.12-2026.09.18.pptx` | 最终 PPT |
| `PPT候选内容.md` | PPT 每一条内容的来源与理由 |
| `PPT生成说明.md` | PPT 是怎么排版的 |
| `周报更新说明.md` | 这周改了哪些规则 |
| `run_log.md` | 运行记录：做了什么、跳过了什么、为什么 |
| `done.flag` | 成功完成的标记 |

> `done.flag` 是「这周已经做过」的标记。它在，就不会重复跑。

## 3. 环境要求

- **Windows 10 或 Windows 11**
- **Windows PowerShell 5.1**（系统自带，不用另装）
- **Python 3.10 或更高**（[python.org](https://www.python.org/downloads/) 下载，
  安装时**务必勾选 `Add Python to PATH`**）
- **Claude Code CLI**（`claude` 命令能跑起来）

不需要 WSL、不需要 Docker、不需要 Linux 工具。

检查 Python 装好没有，在 PowerShell 里运行：

```powershell
python --version
```

## 4. 第一步：装 Python 依赖

在本目录打开 PowerShell，运行：

```powershell
pip install -r requirements.txt
```

要装的东西就 5 个：`python-docx`、`python-pptx`、`openpyxl`、`lxml`、`Pillow`。

> ⚠️ **Agent 自己不会装任何东西。**
> 它只会检查这些包在不在，缺了就提示你运行上面这条命令。
> 它永远不会替你执行 `pip install`。

---

## 5. 第二步：配置 API Key

1. 找到 `.env.example`，**复制一份**，改名成 **`.env`**（前面有个点，别漏）
2. 用记事本打开 `.env`，在最后一行 `ANTHROPIC_AUTH_TOKEN=` 的**等号后面**
   填上你自己的 Key。改完长这样（下面这行是空的，等你填）：

```ini
# 等号后面填你自己的 Key，不要加引号
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN=
ANTHROPIC_MODEL=
```

3. 保存

> 等号前面不要加空格，等号后面**不要加引号**，直接写 Key 就行。
> `ANTHROPIC_MODEL` 留空则用 CLI 默认模型。

**几个要点：**

- `.env` 里是你的私人密钥，**不要发给别人，不要提交到 Git**。
  （`.gitignore` 已经忽略了它）
- Agent **永远不会**打印、记录或上传你的 Key。
  日志里只会显示 `ANTHROPIC_AUTH_TOKEN = sk-abc****（已遮蔽）` 这种形式。
- 忘了做这一步也没关系：运行时会明确提示
  **「请复制 .env.example 为 .env，并填写自己的 API Key。」**

## 7. 第一次使用（七步）

```powershell
# 1. 进入目录
cd C:\你的路径\地产公司公告Agent

# 2. 建立目录、检查环境
.\地产公司公告Agent.ps1 init

# 3. 如果提示缺依赖，装一下（只需一次）
pip install -r requirements.txt

# 4. 如果提示没有 .env，按第 5 节创建 .env 并填 Key

# 5. 把本周公告放进 02_待处理\A股公告\W38公司公告\ 和 02_待处理\港股公告\W38公司公告\

# 6. 先空跑一次，只检查不调用模型（不花钱）
.\地产公司公告Agent.ps1 run -DryRun

# 7. 确认没问题，正式跑
.\地产公司公告Agent.ps1 run
```

> **建议第一次一定先跑 `-DryRun`。** 它只做检查，
> **不调用任何模型、不产生任何 API 请求、不花钱。**

如果 PowerShell 提示「禁止运行脚本」，先运行这一条：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 8. 以后每周怎么用

把公告放进对应周次的目录，然后：

```powershell
.\地产公司公告Agent.ps1 run
```

**不用告诉它第几周。** 它会自己看 `02_待处理\` 里
A股和港股哪一周最全，就用那一周。

想指定周次也可以：

```powershell
.\地产公司公告Agent.ps1 run -Week 2026-W38
```

想先试一下：

```powershell
.\地产公司公告Agent.ps1 run -Week 2026-W38 -DryRun
```

## 10. 自动监听怎么用

```powershell
.\地产公司公告Agent.ps1 watch
```

它会一直开着，盯着 `02_待处理\A股公告\` 和 `02_待处理\港股公告\`（含子目录）。

**它什么时候才会真的开始跑？** 必须**同时**满足：

1. A股有对应周次的目录
2. 港股有对应周次的目录
3. 两边目录都不是空的
4. 两边**连续 5 分钟没有任何变化**
5. `done.flag` 不存在（说明这周还没做过）
6. 没有正在运行的任务
7. 没有人工介入标记
8. 自动尝试次数还没到上限（2 次）

**关掉它**：在那个窗口按 `Ctrl + C`。

> 🔒 **监听器本身绝对不调用任何模型。**
> 它只做本地文件判断。只有条件全满足、真正开始跑的时候，才会调用一次。
> 所以让它开着是**完全免费**的。

**去抖动的意思**：你一次拖进去 200 个 PDF，它会等你拖完。
只要文件还在变，倒计时就重新开始。连续 5 分钟不动了，才认为你放完了。

## 11. 开机会自动启动吗

**默认不会。** 要开机自动监听，需要你自己执行：

```powershell
.\地产公司公告Agent.ps1 install-watcher
```

它会先告诉你打算注册什么，**等你输入 `yes` 确认**才真的注册。

取消：

```powershell
.\地产公司公告Agent.ps1 uninstall-watcher
```

同样会**先问一遍**，输入 `yes` 才删。

> 这两个命令都用**当前脚本的真实路径**，不会写死你的用户名或目录。
> 所以整个文件夹挪到别的地方，重新执行一次就行。

## 12. 周次目录怎么命名

公司公告必须**按周次放在子文件夹里**，命名固定：

```
02_待处理\A股公告\W38公司公告\
02_待处理\港股公告\W38公司公告\
```

- `W` + 周号 + `公司公告`，**中间不要有空格**
- 周号是 ISO 周号，1～53
- `W8公司公告` 和 `W08公司公告` 两种写法都认

`研报\` 和 `新闻资讯\` 是**平铺**的，不用分子文件夹，**允许为空**。

## 15. PPT 的几个要点

- **每条大约 3 行**，不缩字号硬塞
- 小标题**红色加粗**，**以中文句号「。」结尾**，句号后**紧接着**黑色正文
- 标题里**不许用任何括号**（`【】`、`（）`、`[]` 都不行）
- 标题**不能单独占一行**，必须和正文在同一段里
- **同一家公司的多条公告会合并成一条**
- 点评只写一句，只讲数据支持得了的话
- 放不下时的顺序：减少低优先级条目 → 压缩次要信息 → 合并同公司 → 最后才减条目
- **绝不通过缩小字号来塞内容**

---

## 16. Word 的几个要点

- Word 是**完整底稿**，不做筛选、不分类
- **按日期分块**，用**真正的分页符**
- 同一天允许自然跨页，不硬拆
- **保留模板的字体、字号、页边距、页眉页脚**
- 模板**只读**：永远是先复制副本再改，**绝不覆盖 `01_模板\` 里的原文件**

## 17. 繁体字怎么处理

港股公告常是繁体。**最终给人看的中文输出，统一转成简体。**

- ✅ 只换字形
- ❌ 不改数字、金额、百分比、日期、股票代码
- ❌ 不改英文缩写（REITs、EBITDA、H股 等）
- ❌ 不改公告事实本身

用的是 Windows 自带的转换能力，**不需要额外装任何包**。

想检查某个目录还有没有没转的繁体字：

```powershell
python internal\agent_core.py simplify --check --path 05_输出\2026-W38
```

> 这个是**只报告、不改文件**的。

## 18. 常见问题

**Q：提示「未找到 claude 命令」怎么办？**
A：说明 Claude Code CLI 没装好或不在 PATH 里。装好后重开 PowerShell 再试。

**Q：提示缺依赖怎么办？**
A：运行 `pip install -r requirements.txt`。Agent 不会替你装。

**Q：跑到一半失败了会重试吗？**
A：会，但**最多重试 1 次**（共 2 次尝试），不会无限重试。

**Q：会不会漏掉我放的公告？**
A：不会主动丢。判定为无需收录的公告，必须在 `run_log.md` 里
写明**为什么没收**。

**Q：`05_输出\` 里已经有内容了，重跑会怎样？**
A：同周次会覆盖生成物。`02_待处理\` 里的原始文件**一个都不动**。

**Q：能把它挪到别的盘吗？**
A：可以。所有路径都是相对脚本自身位置算的。
挪完重新跑一次 `install-watcher` 就行。

**Q：`个人配置.json` 是干什么的？**
A：个人版专用，用来指向你本地的历史资料目录。
**它是可选的**——删掉它，Agent 照样能完整跑完。
它**不会**进入发行版。

**Q：想让它更大范围地跑怎么办？**
A：`00_配置\Agent配置.json` 里可以调去抖动分钟数、最大重试次数等。

## 19. 安全边界

这个 Agent 被明确限制成**只能做下面这些事**：

**它永远可以做的：**
- 读 `02_待处理\` 里的文件
- 写 `05_输出\`、`04_工作区\`、`日志\`、`发行版\`

**它永远不会做的：**
- ❌ 删除或移动你的公告
- ❌ 覆盖 `01_模板\` 里的模板原件
- ❌ 修改历史资料目录
- ❌ 打印或记录你的 API Key
- ❌ 自动安装任何软件
- ❌ 自动上传文件、发邮件
- ❌ 修改注册表或系统代理
- ❌ 在监听时调用模型（只有正式跑才调用）

## 20. 分享给别人 / 卸载

### 打包分享

```powershell
.\地产公司公告Agent.ps1 build-release
```

生成 `发行版\地产公司公告Agent.zip`。

**打包前会自动扫描一遍**，如果发现你的私人路径、密钥、个人配置，
会直接拦下来，**不生成 ZIP**，并打印：

```
[SECURITY BLOCK]
发行版检测到疑似私人或密钥信息。
不要生成ZIP。
```

包里**一定不含**：`.env`、`个人配置.json`、`03_个人资料\`、
`05_输出\`、`日志\`、`04_工作区\`、Git 信息。

别人拿到 ZIP 之后，只要照本 README 走一遍就能跑起来。

### 卸载

1. 先取消开机自启（如果设过）：
   ```powershell
   .\地产公司公告Agent.ps1 uninstall-watcher
   ```
2. 直接删掉整个文件夹即可。**它是绿色的，不写注册表。**
