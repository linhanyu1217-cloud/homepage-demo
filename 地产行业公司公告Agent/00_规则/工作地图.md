**隔离规则（硬规则）：**

1. **只读本周子目录** —— Agent 一律使用 `REPORT_IN_A` / `REPORT_IN_HK`，
   不自行拼接路径；
2. **不扫描其他周次目录** —— 不使用 `W*` 通配符、不遍历父目录；
   脚本会在日志中显式列出被忽略的其他周次目录，便于回查；
3. **目录缺失或为空 → 记为「本周该市场无输入」**，
   **不报错、不退出、不阻塞**其余步骤；
4. 脚本**不自动创建**周次子目录（只确保 `02_待处理\{A股公告,港股公告,…}` 顶层存在），
   周次子目录由使用者按周投放；

#### 0.6.2 跨市场去重规则（每周生效）

同一份公告可能同时出现在 A股与港股目录中（多为导出时放错位置）。
脚本每周做一次**跨目录去重**，判定顺序固定：

| 步骤 | 比较项 | 说明 |
|---|---|---|
| 1 | **文件名** | 先筛出同名文件 |
| 2 | **文件大小** | 同名但大小不同 → **不算重复**，照常处理 |
| 3 | **SHA256 哈希** | 同名同大小但内容不同 → **不算重复**；哈希不可用时退回「同名+同大小」并注明 |

三项全同 → 判定**完全重复**，标记为【忽略：跨市场重复文件】，
**只处理一次**：本流程保留 A股一侧，忽略港股一侧的同名副本。

**硬约束：不删除、不移动、不重命名任何文件，只在处理阶段忽略。**

统计口径：

```
A股有效数  = REPORT_A_EFFECTIVE
港股有效数 = REPORT_HK_EFFECTIVE
忽略重复数 = REPORT_DUP_COUNT
```

清单落盘：`05_输出\YYYY-Wxx\跨市场重复清单.csv`（UTF-8 with BOM，7 列）——
列为 `忽略文件路径 / 对应A股文件 / 文件名 / 字节数 / sha256 / 判定依据 / 处理方式`。
该清单由脚本生成，run_log.md 直接引用，Agent 不重算。

> **W37 实测**：港股目录嵌套了 `2026911_122825_公司公告\`，内含 22 个与 A股目录
> **同名+同大小+同哈希**的 A股公告。
> → A股有效 **22** / 港股有效 **22**（原始 44）/ 忽略 **22** / 同名但内容不同 **0**。
> 磁盘文件 0 删除、0 移动、0 修改。
