## 三、重点标签怎么用（写周报时）

1. **筛选阶段**：行业公司池全部公司都过一遍，不因为"不是重点"就跳过。
2. **排序阶段**：同样重要的事项，重点房企排前面。
3. **例外通道**：非重点公司出现重大事项（违约、重组、REITs 获批、控制权变更等），
   照常进入筛选结果，不受名单限制。
4. **销售数据阶段**：月底/月初的房企销售数据汇总，**以本名单为口径**，
   不扩散到整个行业池。

**跟踪优先级字段取值：**

| 取值 | 适用范围 |
|---|---|
| 高 | 重点名单中的非建筑系主体（共 34 家） |
| 中 | 重点名单中的建筑系主体（共 7 家，见第一节（五）） |
| 常规 | 其余历史覆盖公司 |

## 五、更新机制

- 本名单**只在使用者更新销售数据跟踪表时同步更新**，Agent 不自行增删。
- 每次更新：修改本文件 + 重跑 `脚本\构建公司池.py`（名单常量 `WATCHLIST` 与
  `WATCH_MATCH` / `WATCH_HK_KEYWORDS` 需同步维护）。
